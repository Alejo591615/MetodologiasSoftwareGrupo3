# Comandos GIT - Jose Londoño

## 1 Comando para crear una rama local

- git branch leolondono + git checkout leolondono

Para crear la rama y pasar directamente a esa nueva rama se utiliza el comando

- git checkout -B leolondono

## 2 Crear un commit en dicha rama

- git add .
- git commit -m "Agregar commit Leo Londoño"

## 3 Subir rama local a repositorio remoto

- git push origin leolondono
